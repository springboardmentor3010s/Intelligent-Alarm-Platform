# Wakeful user guide

## Members
1. **Register** (or sign in through the *Member* portal) and complete the 4-step setup: sleep schedule, goals, challenge types, alerts.
2. **Alarms → New alarm.** Pick time, repeat (every day / weekdays / weekends / one-time / smart adaptive), days, sound, volume,
   how you prove you're awake, snooze rules and difficulty. Use **Edit** any time and **Test** to rehearse.
3. **When it rings** a full-screen challenge appears. Wrong or too slow? A fresh one replaces it. Snoozing (if allowed) makes the next challenge harder.
   Keep Wakeful open in a browser tab and click *Enable* when asked about notifications/sound.
4. **Sleep & mood:** log bedtime, wake time, sleep quality and how productive your day was. This powers sleep adherence and the productivity correlation.
5. **Dashboard / Insights / History / Reports:** habit score, streaks, analytics, recommendations, PDF/Excel exports.
6. **Settings → Coaching:** accept or decline coach invitations; stop sharing at any time.

### Verification methods
| Method | To dismiss |
|---|---|
| Puzzle | solve one puzzle |
| Multi-step | solve 3 puzzles of different types |
| Consecutive | 3 correct answers in a row (a mistake resets) |
| Timed | solve one puzzle against a tighter clock |
| Accuracy check | answer 5 questions, at least 4 correct |

## Wellness coaches
Register as *Wellness Coach*; an administrator approves you. Sign in via the **Coach** portal, invite members by email (they must accept),
then open a member for habit score, wake-up behaviour, sleep and challenge analytics, and send encouragement.

## Administrators
Sign in via the **Admin** portal: approve coaches, manage users and roles, unlock accounts, read the audit log, monitor recommendations,
check system health, send announcements and download the system report.
